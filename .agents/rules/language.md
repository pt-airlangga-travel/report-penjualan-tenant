# Language Rules for report-penjualan-tenant

- Always use **Bahasa Indonesia** for any text generation, UI labels, responses, documentation, and user-facing content related to this project.
- When generating Filament components, ensure `label()`, `placeholder()`, `helperText()`, and other UI-related text methods are set in Bahasa Indonesia.
- Exception: Technical code elements like variable names, database columns, class names, method names, and configuration keys should remain in English to adhere to standard Laravel and PSR conventions.
